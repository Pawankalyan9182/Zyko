# Tejovanam — 10 Minute Delivery

Expo React Native project prepared from the Tejovanam prototype discussed in chat.

## APK build
Use EAS Build with the `preview` profile to create an installable APK.

## Important
The current app contains demo login/OTP (1234), demo order tracking, and local in-memory cart/orders. Real Firebase OTP, database, Razorpay/UPI, live GPS tracking, notifications, and admin backend are not connected yet.

Android package name: `com.tejovanam.delivery`
